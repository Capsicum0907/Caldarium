# Caldarium

[English](README.md) | 日本語

Forge Energy を、作るもの・蓄えるもの・運ぶもの。

*Caldarium*（カルダリウム）は、ローマの浴場の熱い部屋——床下の火で温められる部屋——のことです。

> **状況：開発中・非公開です。** 下に挙げたブロックはすべてゲームに入っています。
> 実際のゲームで動くのを見たもの・まだ見ていないものは [状況](docs/status.ja.md) にあります。

## 中身

| | |
|---|---|
| **発電機** | 9種類。それぞれ別のものを糧にします（下の表） |
| **電池** | エネルギーを蓄えます。同じ段のバーナーの蓄電量の4倍 |
| **充電台** | スロットに入れた物へエネルギーを入れます |
| **ケーブル・導入口・排出口** | この Mod のブロックの間でエネルギーを運びます。他の Mod のブロックに届くのは導入口と排出口だけです |
| **Sol（ソル）** | 人工の太陽。それ自体はエネルギーを作りません |

| 発電機 | 糧にするもの |
|---|---|
| バーナー | かまどで燃えるものすべて |
| るつぼ | 同じ燃料を、溶かしてタンクで |
| ソーラーパネル | 日光 |
| ルケルナリウム | 灯りの光 |
| ヒポカウストゥム | 向かい合う面の温度差 |
| エクスペリエンティア | 画面から注ぎ込む経験値 |
| スポリアリウム | 上に乗った生き物の命 |
| パルス | 叩かれること |
| ビデンタル | 落雷 |

**大きさのあるものには段があります**：銅・鉄・金・ダイヤモンド・ネザライト・ネザースター、
その上に発電機だけが届く圧縮の段が2つ。段の無い発電機はビデンタルだけです。

## 設計

発電機だけでは作ったものの行き場がなく、電池だけでは満たすものがありません。このシリーズの
他の Mod はどれも一つのものですが、これは複数のブロックがそろって初めて一つになるものです。

設計は `docs/` に、話題ごとに1ファイルずつあります：

| | |
|---|---|
| [種類・段・梯子](docs/tables.ja.md) | 表に何が入っているか、行がどこまで登るか、数値がどこから来るか |
| [エネルギーの動き方](docs/energy.md)（英語のみ） | ネットワークを持たないこと、押し出しの唯一の非対称、境界、そして測ったこと |
| [設定](docs/config.ja.md) | すべての設定と、設定ファイル自体に説明を書かない理由 |
| [状況](docs/status.ja.md) | 実際のゲームで動くのを見たものと、その日付 |
| [アイデア](docs/ideas.md)（英語のみ） | 作っていないもの。失くさないように残してあります |

## ビルド

```
run.bat                   # コンパイルして開発クライアントを起動（ダブルクリック可）
gradlew build             # jar を作る
gradlew runGameTestServer # ゲームテストを全部、画面なしで実行して終了
gradlew runData           # テクスチャ・モデル・レシピ・言語ファイルを作り直す
```

`JAVA_HOME` が JDK 21 を指しているか、`java` が `PATH` にある必要があります。

## ロードマップ

- [x] **0** — 土台。Mod が読み込まれる
- [x] **1** — 発電機1種と電池1段を表の最初の行として。触れているものへ押し出す
- [x] **2** — 画面。燃料・進み具合・残量を、かまどと同じ見せ方で
- [x] **3** — 充電。電池にスロットを1つ、同じ考えでスロットを増やした充電台
- [x] **4** — 残りの種類と段を、行として
- [x] **5** — ケーブル。ケーブル・導入口・排出口を段ごとに
- [ ] **6** — 目視ではなくゲームテストで確かめる
