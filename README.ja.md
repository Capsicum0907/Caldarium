# Caldarium

[English](README.md) | 日本語

Forge Energy（FE）の発電機・蓄電器・充電台・ケーブルを追加します。

## ブロック

| ブロック | |
|---|---|
| 火力発電機 | かまどで燃えるもので発電します |
| 溶岩発電機 | 溶岩などの液体燃料で発電します |
| 太陽光発電機 | 日光で発電します |
| 人工光発電機 | ブロック光で発電します |
| 熱電発電機 | 向かい合う面の温度差で発電します |
| 経験値発電機 | 注ぎ込んだ経験値で発電します |
| 生命発電機 | 上に乗った生き物の体力で発電します |
| ダメージ発電機 | 叩かれると発電します |
| 雷変換機 | 雷で発電します |
| 蓄電器 | エネルギーを蓄えます |
| 充電台 | アイテムを充電します |
| ケーブル・インポーター・エクスポーター | エネルギーを運びます |
| 人工太陽 ソル | 周りの太陽光発電機と人工光発電機を動かす人工の太陽です |

発電機は Tier 1〜8、蓄電器・充電台・ケーブルは Tier 1〜6 です。雷変換機と人工太陽 ソルには
ティアがありません。

## 動作環境

| | |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.248 |
| Java | 21 |

## ビルド

```
run.bat                   # コンパイルして開発クライアントを起動
gradlew build             # jar を作る
gradlew runGameTestServer # ゲームテストを実行
gradlew runData           # テクスチャ・モデル・レシピ・言語ファイルを作り直す
```

`JAVA_HOME` が JDK 21 を指しているか、`java` が `PATH` にある必要があります。
