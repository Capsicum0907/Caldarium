# 設定

[English](config.md) | 日本語

[README](../README.md) に戻る。

容量・転送速度・発電量は設定です。ここではコードに書き込める根拠のある数字がありません。
何が適切かは、他に何が入っているかで決まるからです。

ファイルは `config/caldarium-server.toml` で、発電機ごと、種類と段ごとに1節ずつあります。
**ファイルには説明文を書いていません。** 各設定の役目はここに書き、ファイル自体は設定値と受け付ける範囲だけにしています。
値が説明の段落に埋もれないようにするためです。どの数字も出発点で、その先はプレイヤーのものです。

| 設定 | |
|---|---|
| `capacity` | 蓄える Forge Energy の量。発電機は満タンになると止まって待ちます。 |
| `transferRate` | 1ティックに境界を越えられる量（向きごと・面ごと）。充電台がスロットの中身を満たす速さと、発電機が隣へ差し出す量もこれです。 |
| `generatesPerEightTicks` | 発電機が動いている間、8ティックごとに作る Forge Energy。1ではなく8ごとにしているのは、1ティックあたり1未満の値を書けるようにするためです。灯りを読むパネルはこれで2、つまり1ティックあたり4分の1を作り、ブロックは端数を丸めずに持ち越します。 |
| `tank` | るつぼが蓄える燃料のミリバケツ数。1バケツずつ消費します。 |
| `experience.pourSteps` | 経験値の発電機のボタンが注ぎ込む量（経験値ポイント）。後ろに必ず「全部」のボタンが付きます。 |
| `experience.ticksPerPoint` | 経験値1ポイントが燃える時間。その価値は段によって変わります（1ティックに作る量を段が決めるため）。 |
| `sol.durability` | 人工太陽がもつティック数。既定値はゲーム内30日（1日＝24,000ティック）です。 |
| `sol.weatherCost` | 雨や雪が当たっている間、1ティックに減る耐久値。 |
| `storm.natural` / `storm.summoned` | 落雷1回の価値。誰も呼んでいない雷と、呼び寄せた雷の2つです。 |
| `storm.reach` | 雷の落ちた地点からどこまでなら、バイデンタルが受け取るか。 |
| `sol.size` | 球の直径（ブロック数）。描画・当たり判定・選択枠・熱の範囲のすべてがこれに従います。 |
| `sol.reach` | その光が、ソーラーパネルにとって日光とみなされる距離。⚠ 暫定値です。 |
| `sol.burnReach` / `burnSeconds` / `burnDamage` | 熱が球の表面からどこまで届くか（ブロック数）と、その代償。0 なら触れたときだけ燃えます。 |
| `sol.touchDamage` | 球の中にいる1ティックの代償。燃焼のダメージの代わりに、こちらが入ります。 |
| `sol.hold` | 持っている太陽と、持っている体との最小の隙間（ブロック数）。`burnReach` より大きくしておかないと、持っているだけで燃えます。 |
| `sol.glowSpacing` | 太陽の周りの光源のおおよその間隔（ブロック数）。小さいほど明るくむらがなくなり、置くブロックが増えます。 |
| `sol.pulseEvery` / `pulseLength` | 太陽が燃え上がる間隔と、その長さ（ティック数）。長さを 0 にすると燃え上がりません。 |
| `sol.blastReach` / `blastDamage` | 太陽を壊したときの爆発が球の表面からどこまで届くか（ブロック数）と、その範囲の生き物に与えるダメージ。ブロックは壊れません。 |
| `heat.temperatures` | ハイポコースタムの面として、ブロックがどれだけの価値を持つか。ゲームがバイオームに使うのと同じ尺度です。`block=値`、またはタグ全体なら `#tag=値` と書くので、他の Mod のブロックにもこの Mod を触らずに温度を与えられます。ここに載っていないものにしか接していない面は、代わりにバイオームの値を読みます。 |
| `heat.span` | 1つの軸で「満額」とみなす温度差。3つの軸の値は足し合わされるので、3軸とも組んだハイポコースタムは、1組だけのものの3倍を作ります。 |
| `sun.through` | 光がブロックを1つ通り抜けた後に残る日光の割合（％）。上に不透明なものがあれば、この値にかかわらず完全に遮られます。 |

既定値は書き下さず、導出しています。1つ上の段は下の段の8倍の価値を持つので、梯子の途中に釣り合わない段ができず、
新しい段が数字を持たずに追加されることもありません。
